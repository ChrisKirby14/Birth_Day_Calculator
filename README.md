# Birthday Calculator
A simple web-based birthday calculator.

[Try my day of birth calculator](https://bdaycalcstorage.z33.web.core.windows.net/)

**Development Note:** I originally wrote the core logic in Python. To adapt it for the web, I used AI to translate my Python logic into HTML and JavaScript. I then manually deployed the project to Azure Blob Storage to gain hands-on experience with Microsoft cloud infrastructure.
